# Runify

**轻量白盒多智能体平台**

透明可控 · 可视化编排 · 高精度知识召回 · 企业级权限 · 低成本嵌入第三方 · 桌面安装开箱即用 · 100MB~200MB 内存即可运行

> 💡 **告别黑盒与魔法，一切尽在掌握。** 在 Runify 中，每一步推理、每一次工具调用、每一个决策节点都摊开在一张可视化画布上，完全透明、可编辑、可调试。

## 它解决什么问题

大多数智能体平台把推理过程藏在黑盒里，调试困难、行为不可控。Runify 把每一个决策节点都摊开在流程图画布上，让你像搭积木一样组合智能体，并且随时介入、编辑、调试。同时它足够轻——不需要额外准备复杂的运行环境，安装桌面软件即可使用，数据留在自己的机器或内网里。

## 核心特性一览

| 特性 | 说明 |
| --- | --- |
| **白盒可控** | 推理、工具调用、决策节点全程透明，可编辑、可调试、可重跑 |
| **轻量运行** | 启动通常需要 12 秒，运行时占用 100MB~200MB 内存，普通个人电脑即可流畅使用 |
| **可视化编排** | 拖拽式流程图画布，36 类内置节点，应用 / 处理器 / 工具三类画布各配循环子画布 |
| **AI 生成工作流** | 用自然语言描述需求，由系统自动生成蓝图并自动搭建、修改、校验工作流 |
| **知识库与检索** | 富文本文档 + PDF / DOC / DOCX / ZIP 导入，内置全文检索，高精度召回 |
| **上下文管理** | 便签提取、上下文压缩、摘要与分区保存，长会话不丢关键事实 |
| **技能与工具** | 技能文件树、技能商店、自定义工具，以及技能列表 / 下载 / 执行、调用工具等工作流节点 |
| **多模型接入** | OpenAI / Deepseek / Mimo 三类供应商，统一在界面里完成接入配置 |
| **第三方集成** | 企业微信应用 / 机器人、飞书、钉钉、微信公众号、微信个人号 |
| **发布与版本** | 应用、处理器、工具的发布历史与版本回滚，处理器支持上线 / 下线 |
| **角色与权限管理** | 用户、角色、各类资源的细粒度授权，对话记录可追溯、可审计 |
| **可嵌入现有系统与网站** | 支持把对话挂到自有网站，与第三方平台对接，对话端独立入口 |
| **多端适配** | 网页端、桌面端（macOS / Windows）与多人共用的服务器版本 |

## 适合谁

- 想要**完全掌控**智能体行为、不接受黑盒的使用者
- 资源有限、希望在**普通电脑或入门级服务器**上使用智能体的团队
- 需要把智能体接入**私有业务数据**与现有系统的企业
- 需要审批、审计、权限隔离等**合规能力**的业务场景
