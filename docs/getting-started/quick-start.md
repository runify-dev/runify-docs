# 快速开始

本页带你用界面操作跑通第一个智能体，按界面提示点选即可完成。

## 启动与登录

1. 启动 Runify（桌面端双击图标即可；多人共用的服务器版本由管理员提供访问地址）。
2. 启动通常需要 12 秒，运行时占用 100MB~200MB 内存，稍等片刻即可进入登录页。
3. 用默认账号登录：用户名 admin，密码 Runify@1。首次登录后建议尽快修改密码。

:::tip 数据存放
数据默认保存在本地，开箱即用，无需额外配置；如果企业有统一的数据存放要求，可由管理员在「系统设置」中调整，详见 [配置](/getting-started/configuration)。
:::

## 第一步：配置模型

1. 进入 **模型** 页面，点击 **新建模型**。
2. 选择供应商（OpenAI / Deepseek / Mimo），填写密钥与模型名称等参数。
3. 点击 **连通性测试**，确认模型可正常调用后保存。

## 第二步：建立知识库

1. 进入 **知识库** 页面，点击 **创建**。
2. 填写名称后创建，再在目录里新建文档，或用 **导入文档** 批量导入 PDF / DOC / DOCX / ZIP 文件。
3. 文档保存后即可被检索使用。

## 第三步：创建应用

1. 进入 **应用** 页面，点击 **新建**。
2. 可直接选用内置的 **智能体工作流**、**知识库检索工作流** 等模板，也可以创建空白应用从头搭建。
3. 按提示填写应用名称、描述和图标。

## 第四步：编排流程

1. 打开刚创建的应用，进入 **设置** 页的工作流画布。
2. 从左侧节点面板把需要的节点拖到画布上，用连线串起执行顺序。
3. 选中节点后，在右侧配置面板里填写参数（例如选择模型、设定提示词、指定知识库）。
4. 点击 **保存**。

## 第五步：调试对话

点击右上角 **调试**，在对话窗口里输入问题，观察画布上每个节点的执行状态与输出。每一步推理都看得见、可修改、可重跑。

## 第六步：发布

调试满意后，在应用详情中点击 **发布**，改动才会正式生效。之后可在 **版本历史** 里查看历次发布，需要时回滚到指定版本。

## 第七步：打开对话试用

发布后，打开应用的 **公开链接** 或对话入口，即可像终端用户一样与智能体对话。也可以把对话嵌入到自己的网站上。
