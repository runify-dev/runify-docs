# 配置

Runify 开箱即用，绝大多数设置都能在界面的「系统设置」里完成，无需额外准备。日常使用时保持默认即可；只有在企业统一安装、多人协同等场景下，才需要由管理员按需调整。

## 在哪里设置

登录后，从左侧菜单进入 **系统设置**，按分组维护以下内容：

| 设置分组 | 可以做什么 |
| --- | --- |
| 模型密钥 | 集中维护各模型供应商的密钥与调用参数，避免在多个应用里重复填写 |
| 数据存放 | 查看和调整平台数据的存放方式 |
| 登录与安全 | 设置登录策略、管理用户与角色、分配各功能的访问权限 |
| 第三方集成 | 填写企业微信、飞书、钉钉、微信公众号等平台的接入凭证 |
| 用户与角色 | 新增用户、划分角色，并为不同角色分配功能权限 |

## 数据存放

数据默认保存在本地，安装后即可直接使用，无需额外准备。如果企业有统一的存放与备份要求，可由管理员改为企业数据库集中存放，普通用户无需关心具体存放位置。

平台自身数据（用户、角色、应用、知识库等）与工作流运行时连接的业务数据是两回事：后者在 **数据源** 页面单独配置，详见 [多数据源](/guides/datasources)。

## 模型与集成

- **模型**：在 **模型** 页面选择供应商（OpenAI / Deepseek / Mimo）、填写密钥与参数，并用 **连通性测试** 验证是否可用，详见 [模型管理](/manual/model-management)。
- **第三方集成**：在 **系统设置** 中填写各平台的接入凭证，保存后即可在应用里启用对应的集成能力。

## 权限

应用、项目、模型、知识库、技能、数据源等功能都可以按角色分配权限。如果某个菜单或按钮不可见，通常是当前角色缺少对应权限，请让管理员在「系统设置 → 角色管理」中检查。

## 运行环境

一台普通个人电脑（macOS / Windows），或入门级云服务器即可流畅使用。
