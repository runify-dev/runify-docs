# 功能手册总览

功能手册用于帮助你按页面完成实际操作，是一组面向系统使用者的操作说明。如果你还没有进入系统，建议先阅读 [快速开始](/getting-started/quick-start)。

## 管理端模块全景

管理端的功能页面可分为以下几组，手册目前覆盖其中六个核心模块（带链接的页面）：

| 模块 | 说明 | 页面 |
| --- | --- | --- |
| 应用 | 创建应用、概览、工作流、对话日志、调试对话、嵌入配置、应用类型与发布版本 | [应用管理](/manual/application-management) |
| 模型 | 新建模型、供应商与参数配置、连通性验证 | [模型管理](/manual/model-management) |
| 知识库 | 知识库与文档树、富文本编辑、文档导入、检索设置 | [知识库管理](/manual/knowledge-management) |
| 技能 | 技能文件树、文本内容编辑、技能商店、参数设置 | [技能管理](/manual/skill-management) |
| 数据源 | 数据源配置、连接测试、表与列信息 | [数据源管理](/manual/datasource-management) |
| 项目 | 项目、处理器、AI 生成工作流、错误响应、项目概览 | [项目管理](/manual/project-management) |
| 工具 | 自定义工具的字段定义、输出结构与调试 | 工具管理 |
| 第三方集成 | 企业微信 / 飞书 / 钉钉 / 微信公众号等集成的凭证与接入配置 | 集成管理 |
| 用户与角色 | 用户管理、角色管理、权限分配、资源授权 | 系统管理 |
| 系统设置 | 系统级配置、数据存放与登录安全设置 | 系统设置 |
| 对话端 | 面向终端用户的对话入口，支持匿名访问与嵌入自有网站 | 对话端 |

## 阅读说明

功能手册中的页面通常包含：功能说明、页面说明、操作步骤、截图示意。

## 建议阅读顺序

1. 先看 [应用](/manual/application-management)，理解一个智能体从创建到发布的完整链路
2. 再看 [模型](/manual/model-management)，把推理能力接进来
3. 然后按需要阅读 [知识库](/manual/knowledge-management)、[技能](/manual/skill-management)、[数据源](/manual/datasource-management)
4. 最后看 [项目](/manual/project-management)，了解处理器、AI 生成工作流与发布

## 权限提示

各类功能都可以按角色分配权限。如果某个菜单或按钮不可见，通常是当前角色缺少对应权限，请在「系统管理 → 角色管理 / 资源授权」中检查。
