# 工作流引擎

Runify 的核心是一套**可视化工作流**。你通过拖拽式画布，像搭积木一样把节点串联起来，搭建专属智能体，并在运行时看清每一步。

## 看得见的流程图

流程由一张流程图画布表达：

- 节点之间用连线串起来，数据顺着连线流动
- 主流程顺序清晰、可预测，看一眼画布就能理解走向
- 学习成本低，不需要了解复杂的流程规范

**循环也没有被舍弃**：需要重复处理时，使用「循环」节点，在它配套的 **循环子画布** 里摆放循环体，再用 **循环开始**、**循环跳过**、**跳出循环** 三个节点控制迭代。这样主画布始终清爽易读。

## 画布类型

系统按用途提供三类主画布，每类都有对应的循环子画布：

| 画布 | 用途 |
| --- | --- |
| 应用 | 面向用户的智能体主流程 |
| 处理器 | 可被外部系统调用的服务端处理流程 |
| 工具 | 供智能体调用的、可复用的工具流程 |
| 各自的循环子画布 | 承载循环体，节点集合略有差异 |

进入不同画布时，左侧节点面板会自动只显示当前画布可用的节点。

## 白盒执行

这是 Runify 与多数智能体平台最大的不同：**执行过程完全透明**。运行工作流时，画布会实时展示：

- 每个节点的执行状态（等待 / 运行 / 完成 / 失败）
- 每一次推理的输入与输出
- 每一次工具调用的参数与结果
- 流程在条件节点上走了哪个分支

所有这些都是**可编辑、可调试**的——你可以暂停、修改、重跑，把确定性重新交还到自己手里。

## 搭建流程的基本步骤

1. 新建应用 / 项目 / 工具，进入对应的工作流画布。
2. 从节点面板拖入所需节点（面板按 AI、AI 工具、数据、控制流、工具五组组织）。
3. 用连线把节点按执行顺序串起来。
4. 逐个配置节点参数（模型、条件、变量、数据源等）。
5. 运行并观察画布上的执行轨迹，按需调试。

画布还提供自动布局、框选、全屏等辅助操作，主画布可以统一管理所有子画布。

## 节点类型

内置 **36 类**可执行节点，分为五组：AI（3）、AI 工具（12）、数据（5）、控制流（6）、工具（10）。完整清单见 [节点详解](/guides/nodes)。

:::info 关于调用外部服务
调用外部系统或已有能力，请使用「调用工具」节点，或在应用里启用 [第三方集成](/manual/overview) 能力；处理器画布本身也可被外部系统调用。
:::

## AI 生成工作流

除了手工拖拽，项目还支持用 **AI 生成工作流**：用自然语言描述需求后，系统自动生成蓝图、建立任务记录，并自动搭建、修改、校验画布。生成结果仍然是可编辑、可调试的流程图，可以随时人工接管。

## 保存、发布与版本

- 应用 / 处理器 / 工具支持**发布**，每次发布都会留下一条版本记录，可在 **版本历史** 里查看与回滚。
- 处理器额外支持**上线 / 下线**，上线后即可作为服务被外部系统调用。
- 项目可配置统一的**错误提示**，避免内部细节直接展示给使用者。

## 人机协作

通过**审批节点**，你可以在关键步骤插入人工确认环节，让智能体在执行到敏感操作前停下来等你拍板——既保留自动化效率，又守住可控性。
