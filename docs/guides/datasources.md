# 多数据源

Runify 提供独立的**业务数据源**配置，让智能体能查询你自己的业务数据。注意它与平台自身数据是两回事：平台自身数据由系统统一保存，业务数据源是工作流运行时连接的外部数据环境，在「数据源」页面单独配置。

## 支持的数据源

在新建数据源时，先按用途选择类型，再选择具体的产品。界面中常见的选项如下：

| 用途 | 可选产品 | 说明 |
| --- | --- | --- |
| 关系型数据库 | PostgreSQL、MySQL | 支持连接测试、查看表与列 |
| 缓存 | Redis、本地缓存 | 复用中间结果，本地缓存零依赖 |

## 配置流程

1. 进入 **数据源** 页面，点击 **新建数据源**。
2. 选择类型与产品，页面会显示对应的连接信息表单。
3. 按表单填写连接信息，点击 **连接测试** 确认可用。
4. 保存后即可查看该数据源下的 **表** 与 **列** 信息。
5. 在工作流节点中引用该数据源。

## 与智能体协作

| 节点 | 作用 |
| --- | --- |
| 数据库检索 | 执行查询，让智能体主动检索业务数据 |
| 数据库插入 | 把结果写回业务库 |
| 缓存查询 | 复用中间结果 |
| 缓存写入 | 把结果写入缓存，可设置有效期，避免重复计算 |

:::tip 权限
数据源同样受权限保护，可为不同角色分配不同的访问范围，避免智能体越权访问业务数据。
:::
