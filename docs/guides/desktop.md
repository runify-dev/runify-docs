# 桌面端与多端适配

Runify 既是可以双击打开的桌面软件，也可以是由管理员安装在服务器上的版本，不同场景下的数据与文件都会按统一方式保存。

## 网页端

管理界面自适应不同屏幕尺寸，即便在手机端也能处理审批等人工确认操作。对话端是面向终端用户的独立入口，可单独提供给使用者。

## 桌面端

桌面安装包适用于 macOS 与 Windows，安装后双击图标即可运行，无需另外准备任何运行环境。

1. 根据系统下载对应的桌面安装包。
2. 双击安装，按向导完成。
3. 启动后用默认账号登录即可开始使用。

:::info 首次启动
macOS 首次打开时如提示无法验证开发者，可在「系统设置 → 隐私与安全性」中允许打开，之后即可正常使用。
:::

详细安装步骤见 [安装](/getting-started/installation)。

## 数据与文件存放

安装后，平台数据、导入的文档、技能文件以及工作流运行过程中产生的文件，都会统一保存在本机，随用随取、便于备份。桌面端会把这些内容与程序一起管理，普通用户无需关心具体存放位置。

## 单实例够用

对绝大多数个人与小团队场景，桌面端或一台服务器上的单个实例就足以跑满全部能力，无需额外扩展。

## 需要更高吞吐时

如果并发使用人数很多、需要更高的处理能力与可用性，由 IT 管理员扩展服务器版本即可，普通用户的使用方式不变。

## 对话端与嵌入第三方

- **对话端**：可以单独提供给终端用户，对方打开链接即可对话。
- **嵌入自有网站**：在应用里打开 **嵌入第三方**，复制系统生成的嵌入片段，粘贴到自有网站即可挂出悬浮对话气泡；移动端会自动全屏。应用还支持匿名访问，开启后访客无需登录即可对话。

## 适配总览

| 使用方式 | 特点 |
| --- | --- |
| 网页管理端 | 自适应布局，手机端也可审批 |
| 网页对话端 | 面向终端用户，可匿名访问 |
| 桌面端 | macOS / Windows 安装包，双击即用 |
| 多人共用的服务器版本 | 由管理员统一安装，供多人通过浏览器使用 |
| 第三方站点 | 复制嵌入片段即可接入现有系统 |
