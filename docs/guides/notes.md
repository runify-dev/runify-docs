# 知识库与文档

Runify 内置富文本编辑器与文档树，用来沉淀业务资料，并通过内置检索把私有知识喂给智能体。早期文档中的「智能笔记」「笔记检索」是同一功能的旧称。

## 核心能力

- **多要素渲染**：正文、公式、图表与多媒体混排
- **无感自动保存**：实时暂存每一行输入，断网、误触关闭或断电都不丢内容
- **文档树管理**：知识库 → 文件夹 → 文档，支持创建、重命名、移动、删除与内容编辑
- **批量导入**：支持 PDF、DOC、DOCX、ZIP 导入，解析后自动进入检索
- **高精度检索**：内置全文检索，无需另外安装或配置搜索服务
- **删除级联**：删除知识库时会一并清理其下的文档数据，不残留多余数据

## 在工作流里使用知识库

工作流中的 **知识检索** 节点负责把知识库内容接进推理：

1. 在知识库里整理产品规则、业务术语、常见问答，或导入既有 PDF / Word 文档。
2. 在工作流里加入「知识检索」节点，选择召回范围（某个知识库或文件夹）并填写检索词。
3. 智能体运行时自动召回相关内容，生成贴合业务的回答。

召回结果可以交给后续的「AI 对话」节点，或直接作为回答返回。

## 与上下文管理的区别

这两条链路容易混淆，但职责完全不同：

| | 知识库检索 | 上下文管理 |
| --- | --- | --- |
| 数据来源 | 人主动导入 / 编辑的文档 | 会话中模型自动产生的便签与摘要 |
| 使用方式 | 由「知识检索」节点显式召回 | 由「上下文压缩 / 查询 / 写入 / 推送上下文」等节点消费 |
| 用途 | 把私有资料喂给模型 | 长会话记忆，压缩历史、保留关键事实 |

应用设置中的 **便签 / 分区** 用于配置上下文管理行为，与知识库文档树不是一个东西。

## 权限

知识库可按角色分配权限，可在资源授权页面按用户或角色设置。详见 [功能手册总览](/manual/overview)。
