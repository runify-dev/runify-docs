# Installation

Runify is a desktop application you can have running in a couple of minutes. There is nothing technical to prepare — just download the installer for your computer and follow the prompts.

## Install on your computer

1. Download the Runify installer for your system — choose the **macOS** version for a Mac or the **Windows** version for a PC.
2. Double-click the downloaded installer and follow the on-screen prompts to install Runify.
3. Launch Runify from your applications folder or Start menu.
4. Sign in with the default account:
   - Username: **admin**
   - Password: **Runify@1**

:::tip
For security, change the default password after your first sign-in, especially if other people can access the computer. You can do this later in System settings.
:::

## For larger teams

An IT administrator can install the server edition on a server so that everyone on the team can sign in from their own computer.
